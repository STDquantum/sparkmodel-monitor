# 商品历史浏览器

双击根目录“浏览商品历史.bat”。首次运行会读取 Git 历史并生成 `history/index-cache.json`，之后在提交或目录变化时自动重建。保持启动窗口打开，关闭窗口即可停止。需要 Git 和 Python 3.9+。

以 `properties.Product number` 为货号，去除首尾空格并忽略大小写。同货号的多条记录会并列显示；无货号的记录按 ID 分开。时间为 Git 提交时间。只展示快照中发生变化的版本，包括字段、记录和已跟踪图片的变化；移除后重新出现也会记录。图片从对应 Git 提交读取，无法还原从未提交的内容或仓库中缺失的图片。当前工作区目录有未提交字段变更时也会显示，但单独修改未提交的图片不会生成版本。仅使用当前分支的第一父线，不包含其他分支。

本工具只读取仓库数据，缓存可随时删除，不会修改原商品资料。
